Technical details for developers
  • Plain HTML, CSS and JavaScript, no frameworks. Data code lives in api.js, rendering in widgets.js, page interactions in script.js.
  • Every request goes through one fetchJSON() helper using async/await, with a 10-second timeout (AbortController) and friendly error messages.
  • Each widget shows skeleton placeholders while loading and a Retry button if a request fails. Widgets load independently, so one failing API never breaks the others.
  • GitHub responses are cached in sessionStorage for 10 minutes to stay under GitHub's 60 requests/hour limit.
  • Theme, last city, news topic and added skills are remembered with localStorage.
  • Accessible: skip link, keyboard-friendly tabs and menus, aria-live updates, and animations switch off when "reduce motion" is on.
